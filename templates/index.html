Studi Kasus

Penjual es krim ingin mengetahui seberapa besar suhu udara memengaruhi pendapatan harian. Dengan model regresi linear sederhana, dibuat perkiraan pendapatan berdasarkan temperatur, sehingga stok dan persediaan dapat disesuaikan sebelum cuaca panas tiba.

Dataset yang digunakan berisi data suhu dan pendapatan harian, dengan hanya satu fitur numerik sebagai variabel bebas dan satu target numerik sebagai variabel terikat.

Interpretasi Model

  • Koefisien suhu: setiap peningkatan 1°C diperkirakan meningkatkan pendapatan sekitar $ {{ metrics.coef | round(2) }} untuk setiap unit suhu.
  • Intercept: saat suhu 0°C, model memprediksi pendapatan sekitar $ {{ metrics.intercept | round(2) }}. Nilai ini membantu memahami tren dasar, namun perlu diinterpretasikan dengan hati-hati karena pada suhu dingin penjualan es krim cenderung turun.
  • RMSE: selisih rata-rata prediksi dengan data aktual sekitar $ {{ metrics.rmse | round(2) }}.
